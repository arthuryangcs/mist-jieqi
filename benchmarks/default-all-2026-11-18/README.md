# 兼容全特性默认测试证据

全部为本项目自生成合成局面、冻结两秒对照和本地回归，无用户棋局、原始采样、二进制、凭据、PID或额度。matches.json保留8局全部实际结果，待裁不算和棋；公开账本仅将仓库内绝对构建哈希键改为相对路径，原棋谱和参数不变，重放与独立审计重新通过，redaction.json记录证据。

本轮15样本丰富HCE+残差NNUE默认由用户要求开启，不表示已证明棋力改善；同64MiB/最多4线程/每手2秒上限，不表示实际RSS或线程利用一致。详情见[报告](../../docs/experiments/default-all.md)及[代码](../../native/experiments/default-all/README.md)。
