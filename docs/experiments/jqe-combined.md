# JQE snapshot + FMA：独立组合验证

2026-11-18。这是新的可选候选，不是原 JQE 32 局确认的替代版本。默认保持 HCE；原确认二进制、模型和结果均未变。本轮没有重启8766、v5或旧JQE试玩，也没有刷新用户棋局。

## 改动及证据

先前同机采样显示神经correction和memmove为主要热点，snapshot、FMA单项已分别测得约18%和26%的固定树加速，但组合没有测过。本轮只组合这两项，不加入此前收益不可靠的integer变体：

- snapshot只复制有效模式和宽度的累加器，并保留stock、board、bucket；量化it014两方有效累加器共1028字节，另复制元数据。State物理大小仍12448字节，保留堆上的逐层Undo及整体State恢复检查，并非缩小状态布局或改用逆运算撤销。
- 仅对`mist_jqe::correction`使用`__attribute__((target("fma")))`，保留`-ffp-contract=off`和显式FMA语义，没有fast-math或全引擎架构开关。

it014及600/430比例不改，8暗世界/1明世界、固定观察与采样世界、搜索覆盖、根聚合、节点定义、TT64MiB和工作线程设置不改。不改变开局经验规则，也不输入真实暗子分配、对方私有暗俘或裁判种子。

组合候选源码与snapshot相同，SHA256为`53547841d43e08bd7fc2e49b026e2ccad17d6140da3c4daaf86fa390ad04226a`；头文件SHA256为`d9c0f8e894c574f2a4af37e7b9735c9f1e19eb8bbaf042383a25fb46edad1555`。普通二进制SHA256为`2ea35ae680c063ffb5177ce8b32c5a2ef13f89ce34fd6250c9337d4190b0ffcb`。模型仍为`f90bd44e8ee244405eb08eb4f784e3f156900f0691f651b5124d50032f8ba160`；原JQE二进制仍为`952b810695d985d4c927c03f250007e4af9b99b553eff32251cbaf53a058744a`。

## 正确性和资源

20个定向检查（5局面×浮点/量化×普通/ASan+UBSan），612次转换的整体State恢复通过。普通/消毒器各414个规则观察视角及11874次转换通过，覆盖合法应手、揭子、库存和吃方独知的暗俘。1/4工作者固定树逐层节点和所有分数严格相等；全明已知世界复制仅用于覆盖4工作者的正确性测试，正式比赛全明仍1世界。

0/5/25/100ms中断后恢复检查通过；真实异步工作者上127层push/pop、随后触发安全保护并恢复整体状态通过，这不是127层完整搜索。8线程共16000次只读推理一致。没有重跑独立上游推理oracle，没有新增其他维度/王位分桶模型，没有ThreadSanitizer证据；ASan/UBSan和并发一致性不能代替TSan。

CPU特性只读动作`sysctl -n machdep.cpu.features`返回`Operation not permitted`，该查询被拒且未重试，也没有换接口查询受限CPU信息。本轮沿用同一授权x86-64 Mac已有的FMA执行记录，并完成组合实际运行检查；不声称重新获得了CPU特性查询结果。这是本机FMA可选构建，不分发二进制，不作为可移植默认。

旧qcheck暂停锁原样保留，没有读取系统进程列表或处理未知旧进程。只依据已完成任务账本、已知运行锁和本任务自持进程管理防重叠；不能证明没有任何无关后台争用。稳定8766搜索活跃时自身工作暂停，未启动或重启任何试玩。原HCE/JQE/Pika均限制每手2秒、最多4搜索线程、TT预算64MiB；总RSS、TT条目容量和实际工作线程利用不同，尤其全明单世界Mist只有1个工作者而Pika可用4个，不能声称完全相同实际利用率。
