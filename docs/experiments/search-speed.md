# 搜索速度候选：精确缓存、增量评估与根任务调度（2026-11-03）

当前为非默认实验。目标是同预算下真实提速；**尚未全面超过固定 Pika，更没有证明棋力超过 Pika**。本轮把此前本地累积的已验证候选整理为独立可构建代码；默认 HCE 服务、用户棋局及旧 qcheck 暂停赛事均未改变。

## 实现与隔离

代码在 [native/experiments/search-speed](../../native/experiments/search-speed/README.md)。保持原 HCE、暗局 8 个采样世界及全部合法根着；全明只需要 1 个世界。没有混入 NNUE、额外估值、扩大样本、LMR 或空步剪枝。合法视角采样来自可见信息，不接收裁判初始布局种子和真实暗子身份。暗俘仅捕获方得到身份，另一方保持未知。

- 精确上下文 TT：样本棋盘、观察者、剩余库存、静态将军延伸余量、重复历史计数、闲步及总步数参与身份；评分只在相同剩余深度复用。修正旧缓存路径依赖反例，不是把容差放大。
- 原 HCE 增量状态与小 Undo：撤销还原棋盘、库存、位置哈希及规则历史；浮点求和顺序变化以 1e-7 对照验证。公式和棋子权重没有改变。
- 静态 stand-pat 达到窗口时先证明有合法着，困毙仍优先判负。只在正深度构造 TT 键，qsearch 的规则历史保留。
- 暗局按根着×采样世界调度，每个世界同时只有一个任务使用其状态/TT；全明按独立根状态调度，少根着时使用下一实际走子分解和已证明窗口。4 线程上限，私有棋盘、缓存和历史排序表。
- 缓存分配总预算 64 MiB；不是整个进程内存保证。无人工主搜索层数上限，仍保留 127 半回合的栈/整数安全边界、时间取消和过期响应防护。
- 全部根着已被规则结算时直接返回，不将零节点循环次数冒充搜索层数。该情况推荐存在，但 mainDepth/completedDepth/selDepth/nodes 均为 0，明确标记 root-adjudication。

协议 3 仅给独立候选增加公开重复/时钟上下文；默认服务继续协议 2。候选未接入页面，没有进行新的浏览器视觉验收，也未重试此前中止的浏览器访问。

## 正确性与测试

本机 Release、ASan/UBSan、ThreadSanitizer 分别通过 36 个固定深度/固定世界对照、326 项 TT/静态窗口断言、12 次时间中断、暗子与暗俘信息隔离、重叠请求拒绝、取消与取消后再搜索。Release 与 ASan/UBSan 各通过 414 个视角、11,874 次走子/撤销的 JS 规则/HCE/库存对照。

独立 JS 穷举另覆盖 8 个小深度用例（双方、明/暗子），另有 6 个重复责任与闲步/总步数边界用例、285 项静态叶子断言和零节点结算显示检查。旧 `全明/49033/11` 深度 5 指定走法 16→25 原有 206.666.../203 差异保留为回归，新值为 203，与无 TT 参考一致。整理测试时曾把这个指定走法值误断言为最佳着值，修正测试后通过；没有把它报成引擎缺陷。

项目现有 JS 测试 151/151 通过。固定 Pika 19 个公开局面的 FEN、库存与 perft-1 合法着核对通过。独立候选 CI 会运行 Release 和 ASan/UBSan；本机另测 TSan，不冒称 CI 已覆盖线程消毒器。

## 不保留的方向

均保留本地原始负结果，不把局部收益叠加成整体提速。下表是各自固定工作集的耗时加速比几何均值，不能跨集合相乘；小于 1 表示变慢。

| 方向 | 固定工作加速比 | 最差局面 | 决定 |
|---|---:|---:|---|
| 士象位置集合 | 0.9890 | 0.8359 | 排除 |
| 公开合法着共享缓存 | 1.0141 | 0.7986 | 排除 |
| 行列位占用将军判断 | 1.0427 | 0.8417 | 排除 |
| 暗子估值分量缓存 | 0.9728 | 0.7833 | 排除 |
| 正深度延迟 TT 键 | 1.0618 | 0.9776 | 保留，另做独立固定时间集 |
| 延迟历史摘要 | 0.9480 | 0.7760 | 排除 |
| 车炮目标位集合生成 | 1.0175 | 0.9439 | 排除 |
| 空闲线程细粒度拆分 | 0.5580 | 0.1664 | 排除，失去缓存复用/增加工作 |
| 拆分加 512 节点粒度 | 0.5543 | 0.3008 | 排除 |

延迟 TT 键的 72 次固定工作对照只说明该项的同树成本；独立 2 秒集相对立即前序在各阶段约 1%–2%，不能宣称全引擎提升 6.2%。细粒度拆分虽然能用上空闲核，反而丢失 TT/PVS 复用、增加节点；没有用重复工作增大 NPS 来宣称成功。
