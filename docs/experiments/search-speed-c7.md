# C7 行列提取与自将检查：本地性能验证

本轮保留 C7 为可显式选择的实验候选，生产默认不变。目标“全面超过固定 Pika”尚未达到。这里的 NPS 都是各引擎原生统计，Mist 已合计所有样本，不能再乘 8；跨引擎 NPS 不能直接解释为同等搜索工作或棋力。

## 修改与正确性边界

C7 在已发布 C6 上增加共享行列查表、从现有 90 位占位提取行列的无新增状态实现，以及有独立证明的远射线无影响判定。车炮生成与将军检查共用约 80 KiB 不可变表。State 与 Undo 声明不变。当前被将军、将帅移动、马腿/象眼可能改变或异常王位提示保持完整合法性检查。

没有降低暗子样本数、改变 HCE、删减根着、修改节点定义或写死兵位开局。取消、时间、内存和栈安全保护保留。只接受当前观察者可见信息；暗俘身份只提供给吃子方。源码沿用 GPL-3.0，没有新增第三方实现或权重。

## 速度结果

固定工作 40 请求：相对 C6 耗时加速比几何平均 1.0725，最差 0.9986。暗局节点数一致；全明分支因既有并行调度可能有少量节点数差异，逐项记录未删去。

已见开发集 12 局面 × 3 引擎 × 6 次 = 216 请求，零技术失败；每个局面覆盖全部 6 种执行顺序。相对 C6 原生 NPS 比几何平均 1.0684、最差 1.0033，11/12 高于同批 Pika；第二个早期开局仍明显落后（约 7.02M 对 9.08M nodes/s）。这批数据已参与开发，不能称为独立留出。

确认集 14 局面 × 3 引擎 × 6 次 = 252 请求，零技术失败。12 个主要局面中有 11 个此前项目基准未见视角，另一个是重复全暗初始控制；额外两个已见困难残局明确分开。项目视角哈希扫描范围及冻结哈希清单随数据保存，不声称棋局在全世界首次出现。稀疏编辑残局库存合法，但未证明可从初始局面到达。

主要确认集中 10 个长搜索局面：相对 C6 原生 NPS 比几何平均 1.0633、最差 0.9907；其中 8/10 高于 Pika。重复全暗初始控制本轮约 5.49M 对 Pika 5.89M，仍有差距。两个已见难残局的 C7/Pika NPS 比分别 0.721 和 0.455。

两个短搜索单列延迟：C7/C6/Pika 中位耗时分别为 14.31/14.99/639.48 ms，以及 10.21/10.25/3.86 ms。不能把提前结束搜索的低 NPS 等同更慢的结果；原日志没有保存终止原因和评分，报告不补造原因。

各局面的全部数值、离散范围、主搜索与选择性最深路径、节点和耗时在 `benchmarks/search-speed/c7-2026-11-03/`。Pika 原 UCI depth 与 Mist 半回合指标含义不同，不直接比较为同等层数。

## 资源诊断

另做 45 次自持子进程 CPU 诊断（9 次就绪控制、36 次搜索），不混入上述计时。只用自己启动并等待的 Node/引擎子树的 `getrusage(RUSAGE_CHILDREN)`，不读取系统进程列表或附加其他进程。先用祖孙子进程控制验证 CPU 计数，再减去各引擎就绪 CPU 中位值估计搜索开销；结果有启动和关闭误差，每组只有 3 次。

C7/Pika 估计 CPU 时间除搜索墙钟：全暗初始 3.48/3.94，第二开局 3.84/3.93；两个困难残局约 3.52/3.94、1.73/3.95。C7 自报进程 CPU 提供独立交叉核对。四线程配置不保证四核持续占满；困难单世界残局的尾部并行仍有明显空间，全暗初始也存在较小空隙，而第二开局更偏向每节点成本。

## 正式对战与验证

12 局全部结束：C7 对 C6 为 2 胜 0 和 2 负（50%），对 Pika 为 1 胜 0 和 3 负（25%），对未改生产版诊断为 1 胜 0 和 3 负（25%）；没有技术失败、超时判负或未决。Pika 的一场失败因公共第三次重复判负，其余三局 Mist 被将死。完整独立回放核验 1,195 步及 22 次暗俘可见性。C7 596 手中有 1 次正常 host 时间保护停止、0 fallback；C6 0 host stop，生产诊断 206 手均由既有 host 时间保护终止搜索。两个全新布局、换色，对 C6、固定 Pika 及未改生产版各 4 局；不按中途比分增减样本。C6 为主要同资源内部控制，生产版仅诊断，不能混称同规则同内存的稳定控制。

三方每手预算上限 2000 ms、搜索线程上限 4；C7/C6 TT arena 与 Pika Hash 均 64 MiB，RSS/线程利用率不能完全一致。Mist host 及 core 留出的时间保护合计约 75 ms，Pika host 留出约 40 ms，实际搜索时长分别约 1.935 与 1.960 秒；不称完全相同有效搜索时间。公共裁判终局优先，第三次重复责任方判负，120 静着和，400 半回合未决单列。Pika 固有内部重复搜索不改，只加公共根着过滤；旧生产版内部重复及 TT 容量差异披露。

此前 C6 赛事两次零节点裁定响应缺诊断开关被测试器误判为技术失败，原记录和计分保持不动。本轮测试器针对已裁定/终局响应单独校验，不重赛覆盖旧结果。

## 正式发布包检查结果

精确生成源码及本机二进制均与比赛版本相同。独立发布包共 14 项命令全部通过：155 个 JavaScript 测试；release、ASan/UBSan、TSan 各 3 组专项单元（第一组 546,151 个断言）、40 个有限搜索对照、6 个时间预算、重叠请求拒绝、取消/立即取消、隐私及零节点根裁定；各 414 个规则视角与 11,874 次走子/撤销转移；各 3 个独立无 TT 深度参考（保留 203/206.667 历史反例）。公开棋谱回放再次通过，移植后的 CPU 诊断入口仅做就绪冒烟检查，没有把它称作重新完成 45 次诊断。详见数据目录 tests.json。

本轮没有 UI 改动，没有重试此前受限的浏览器读取；逻辑测试不作为真实浏览器视觉验收。生产源码、二进制、用户棋局和旧暂停赛事均未修改。

后续仍需解决全暗开局每节点成本和并行尾部等待；当前保留的 C7 只是阶段性可回退候选，不能根据这次小样本默认启用。
