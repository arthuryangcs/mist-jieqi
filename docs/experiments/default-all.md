## 实现与正确性

`base.cpp`是旧all-features自有组合的可审计自包含快照，`source.mjs`逐锚核对生成当前方案，不依赖旧私有编译缓存。迁移根结果0..4、将死优先的步数上限，内部循环采用当前静态启发式截断，不能将循环本身当作和棋或犯规结论。只有裁判可证明单方连续三个完整循环长将才判负，其他长捉/混合重复保留待裁，尚不是完整竞赛裁判。

首次定向循环检查发现：风险排序再次降低已被规则判负的根着分数，首个差分`-5169.878728264789`对规则参考`-3594.878728264789`。责任标记没有错，但规则分数不应由启发式修改。保留首次失败证据；修复后确定的胜/负/和根结果保留原聚合分，风险权重/惩罚归零。普通和ASan/UBSan的全部24个循环专项通过，含双方颜色、长将责任方与最后落子应将方区别、未够三循环、伪造重复、揭子上限混合将死、未决优先。

普通与ASan/UBSan各36观察视角、1020走子/撤销，666次揭示、21次暗俘，63项观察者隐私及241项概率/风险核对通过。独立JS活动/攻防/NNUE前向与C++一致；完整库存TT碰撞/替换/代溢出、压力缓存、惰性边界、空步保护/验证/异常撤销/虚拟TT隔离、杀棋距离和64MiB上限均通过。没有新ThreadSanitizer证据。

独立临时端口实际服务测试确认页面/后端、配置与二进制来源、新默认15样本合法推荐、NNUE和其他特性计数；重复编号409、取消和先取消的过期请求、隐藏真值400、外站Origin403均通过。正式赛程适配器另测重叠拒绝、取消和恢复。没有接管现有页面，没有做浏览器视觉验收；HTTP与界面逻辑回归不冒称视觉测试。
