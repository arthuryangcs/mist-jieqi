# 同一行棋方循环路径扫描实验（2026-10-27）

本轮固定一个路径循环查询优化，完成同树计时与12局新布局换色筛选，保持非默认。五个固定局面中位速度比为0.995～1.002倍（大于1才更快）。不根据输赢换算法、改预算或增加比赛；没有叠加NNUE、插入排序、棋子位图、stand-pat、几何表或预留量实验。算法和规模见[计划](../../native/experiments/cycle-parity/plan.json)。

## 依据与等价边界

稳定基线提交 da1ab8ce11659110f19422213c5811cbfab77cb6，源码SHA-256 `94dab5ee87ff8996fcf9e8f93070a8012866926822611eb0f84f6bd3607e1b2c`。当前search在每个节点用std::find扫描路径Key；Key包含行棋方，而每条真实搜索边由push翻转行棋方。当前没有空步或不落子而继续追加同方路径项的递归；PVS重搜在前次调用返回、路径撤回后进行。不能相等的另一方历史项因此可以跳过；不改变棋盘、估值或搜索树。既有[走法与路径栈报告](../../NATIVE_MOVEGEN_REPORT.md)保留了路径栈演进证据，本轮不混用其中历史速度比。

新函数根据路径首项行棋方选择起点，保留原前向顺序，再隔一项比较完整Key；不将遍历方向作为额外优化变量。仍比较两个棋盘哈希、行棋方、双方私有库存数量/价值及原扩展字段。即便棋盘相同，私有库存不同也不会误作同一Key。空/单项、奇/偶长度及首项与查询同方/异方均处理。没有新缓存、跨世界/请求信息、节点剪枝或降低样本。

搜索内循环仍增加原cycles计数并返回原0分，影响TT写入的循环保护不变；根第三次公开重复时落子方判负仍由原根元数据与JS裁判执行。深层循环仍是原提前截断近似，不把本轮优化当成更完整的重复责任搜索。路径push/pop、异常/超时撤回、PVS/TT、qsearch、将军延伸及节点检查不变。

本机已有Clang、C++17、-O3、NDEBUG、-ffp-contract=off，不启用fast-math，不安装依赖、不下载第三方代码。编译工具只复用standpat/build.mjs的参数；默认源码与二进制均未覆盖。

## 正确性与性能

发布版与ASan/UBSan各通过 438 个视角、11151 次走子/撤销、10组固定节点搜索。合法走法、将军、困毙、马腿/象眼/炮架等对照独立JS规则；估值、公私库存、翻子、恢复状态及逐层全部候选/评分/节点与稳定版一致。任意压力摆图不主张库存合法。项目 142/142 测试通过。

[路径专项探针](../../benchmarks/cycle-parity/cycle-probe.json)发布及内存检查版本各核对 139112 组查询，路径长度0到160、两种起始方、奇偶长度、空/单项、匹配/不匹配与多次重复Key，全部与原std::find一致。另逐项改变完整Key的8个字段，确保四项私有库存字段及扩展字段都未忽略。随机种子固定2026102707，不涉及裁判真实暗布局。

ASan/UBSan与探针在每次查询检查路径行棋方交替，并逐次与原完整扫描比较；发布正式搜索不运行这些诊断。无节点上限的实际最多4线程路径另核对发布版及内存检查版各5局面，逐层全部候选、评分、推荐与节点相同；超时展开后检查每世界状态恢复。全明1样本仍单线程，见[规则检查](../../benchmarks/cycle-parity/check.json)、[内存检查](../../benchmarks/cycle-parity/check-sanitized.json)、[并行检查](../../benchmarks/cycle-parity/parallel-check.json)。

## 同预算新布局换色对局

2026102701/2026102703 两个新布局及顺序在对局前冻结，并核对不重复此前已提交matches.json记录的初始布局。每布局红黑互换，4局试验对稳定，另8局稳定/试验各对固定Pika4局，交替执行。所有搜索串行，每手双方名义1000ms、共同60ms宽限；就绪在计时外，公开投影、采样、编码、IPC、FEN/根规则核对及搜索触发的停止/回收在内，局末关闭常驻进程另行完成。宿主额外预留均为0ms；两版C++原有最多35ms核心收尾余量一致。Mist均8样本、全明1样本、最多4世界线程、每世界9万TT、主深度上限8。

固定PikaJieQi仍为已授权二进制 `bcc83f88` / `f32d3c6dfe4d6d90da7728d9cc2af68c3195a1cefb1bc28f3829f174c518dba1`：HCE、NNUE关闭、4线程、Hash64MiB、MoveOverhead0；已知颜色估值不对称保留。未修改、下载或重编译第三方，未改安全设置。

本轮统一名义时限及最多4个搜索线程；两实现缓存组织不同，没有将峰值RSS限制为完全相同，因此不宣称严格等内存下的优劣。

## 信息边界与限制

仅行棋方publicState进入搜索；真暗布局和裁判种子不传引擎。暗俘身份仅吃子方可见；未知离盘身份仍作为库存潜变量，采样无放回。代码拒绝公开暗子/暗俘携带真实身份，真实隐藏布局变化不改变公开观察与固定采样。独立回放 966 步、99 次暗俘信息、3 次重复判负、0 次Pika根约束触发通过，见[原始对局](../../benchmarks/cycle-parity/matches.json)及[回放](../../benchmarks/cycle-parity/verification.json)。

本轮试验对稳定版为2胜0和2负，对Pika为2胜0和2负；同批稳定版对Pika为1胜0和3负。同树计时和预算层数不代替棋力确认，因此维持默认HCE及原路径扫描实现。

仅两个相关布局对，未完成独立确认；不能从小样本得分率归因算法改动造成棋力提升。较高得分、更多节点或终局高层/零节点元数据均不能证明超越Pika；不据此估算Elo。概率估计仍受8个相关平衡样本、固定HCE对手及搜索循环近似限制。实验发布不等于默认启用。本轮无UI改动，未做真实浏览器验证；项目单元测试不等于浏览器验收。

复现和暂停恢复步骤见[实验README](../../native/experiments/cycle-parity/README.md)。冻结源码和二进制变更会拒绝续跑，已有记录不可覆盖；第三方、构建产物、凭据及账户额度数值不发布。
