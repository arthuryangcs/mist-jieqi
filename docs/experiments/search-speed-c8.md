# C8 非滑行棋子走法预计算（2026-11-08）

本轮完成实现层面的速度实验，**保留为可选候选，不默认启用**。固定相同搜索树的加速比为 **1.048**；每手 2 秒确认集的原生 NPS 比为 **1.038**，但最差局面为 **0.950**，未通过事先设定的最差局面 0.97 门槛。没有全面超过 Pika，也没有依据把速度收益解释为棋力提升。

## 改动与依据

对新建的合成测试进程做 CPU 采样，非滑行棋子的候选生成与排序是主要热点之一。C8 把马、象、士、兵的边界、马腿/象眼位置、暗士九宫和暗象河界预计算为 **24,480 字节只读表**，保持旧候选顺序。真实占位、己方目标和 captures-only 限制仍即时检查。将帅、车炮、不安全的王位提示继续使用 C7 路径。

C7 的 State/Undo、评价、TT、搜索和计时部分逐字保持不变；源码范围测试从公开局面/TT 定义起核对整个后缀。8 个暗子样本、原 HCE、全根覆盖、原节点口径、时限、取消、栈保护和信息隔离均未改。额外表不计入 TT，但总 RSS 不完全相同。无新第三方代码、权重或运行依赖，沿用 GPL-3.0。

C8 生成源码 SHA-256：`a17db66bebc4cfabe9bc0d48a5f4b1693bb9306b1af5397907a0c601afc80047`。本机二进制 SHA-256：`188951846a541667fc32ee7ebd5eccb5f53b11ab97b95af8e11631137350e3ae`。二进制哈希与工具链有关，跨平台以源码校验和测试为准。C7 基线来自 fe810c7，生成源码为 `855cccb05cff5a4eb3efa919546f41d7b66ae7b852490ecf0b81115f7f9f20d0`。

## 相同搜索树耗时

8 个已见开中局面、完整 4 层、8 样本，每局面 4 次交替顺序，共 64 请求、32 对。逐对要求全部候选顺序、逐世界分数、每个完整迭代及节点数一致，全部通过。

各局面核心耗时中位数加速比的几何平均为 **1.048**，范围 **1.004–1.085**，等价于这组基准平均约 4.6% 的耗时减少。全暗开局中位数由 210.5 ms 降为 194.1 ms。较短的有限深度结果不能代替两秒比赛预算结果；完整数据见 fixed-work.json 和 fixed-work-summary.json。
