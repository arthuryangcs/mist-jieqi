# JQE：独立的等价提速实验

日期：2026-11-09。完成144局当前规则复测后才开始采样、编译、验证与计时；全部串行，未与比赛争抢CPU。**没有改变默认HCE、冻结JQE、比赛调度器或8766服务，没有合并或启用变体。** 后续棋力确认应继续使用原冻结候选，不能直接换成本报告的速度变体。

## 结论

- 仅复制有效神经累加器的snapshot变体：五局面中位数速度比为 **1.170～1.216倍**，几何平均 **1.184倍**。
- 仅对NNUE correction函数启用硬件FMA的fma变体：**1.242～1.279倍**，几何平均 **1.258倍**。
- 去掉量化第一层浮点往返转换的integer变体：几何平均 **1.008倍**，配对结果跨过1.0，**没有足够依据认定有实际收益，不建议采用**。

三个变体都通过所列等价性、规则与安全检查。前两个结果支持继续研究独立提速方案，但**不是棋力优势证据，不构成默认启用JQE的依据**。两个提速幅度不能相加或相乘；组合版本没有构建、测试或计时。

## 实际CPU采样

对原冻结JQE的开局、揭子较多的20步中局和全明残局分别进行3秒`/usr/bin/sample`采样；引擎请求预算5秒。采样只针对本实验创建的子进程，没有连接试玩服务。

开局的顶部栈计数：`mist_jqe::correction`为2507，memmove为1075，明确标记的fmaf跳板为281，另有642个未命名数学库样本。中局对应2441、1278、315和771。残局对应848、444、99和181。调用树显示数学库调用来自correction。等待栈不计作CPU热点；这些计数不是运行时间百分比，也不是提速率。

采样据此支持优先减少快照复制及显式FMA调用开销。详见[脱敏采样摘要](../../benchmarks/jqe-speed-2026-11-09/profile-summary.json)。含本机路径及主机信息的原始采样报告仅留在本地，没有导出。

## 变体与运行条件

基线重编译后的二进制与144局比赛冻结JQE逐字节相同，SHA256：

`952b810695d985d4c927c03f250007e4af9b99b553eff32251cbaf53a058744a`

原模型it014保持不变，SHA256：

`f90bd44e8ee244405eb08eb4f784e3f156900f0691f651b5124d50032f8ba160`

使用同一台x86-64 Mac、Apple clang17、`-O3 -ffp-contract=off`，没有fast-math。硬件查询确认FMA、AVX及AVX2。模型、搜索规则、根聚合、库存键、固定观察/采样世界、TT预算及线程设置均保持一致。

1. **snapshot**：原神经State为12448字节，含两模式、最大1024维的数组。it014量化有效数据只有双方各257个int16，共1028字节。新helper按视角复制所选模式的有效宽度及stock/board/bucket，保留未用数组为初始零值、整体State恢复比较和堆上逐层Undo。没有用逆运算撤销，也没有改变状态布局。
2. **fma**：仅给`correction`加`__attribute__((target("fma")))`；保留显式融合与原浮点计算顺序约束。该实验二进制针对本机已验证的FMA能力，不能当作可移植默认二进制分发。
3. **integer**：量化L1激活直接存为int16，移除float→int往返；其余计算保持不变。

实现及使用方法见[native/experiments/jqe-speed](../../native/experiments/jqe-speed/README.md)。所有生成源码、头文件和二进制都在独立缓存目录，未修改原冻结构建。

## 固定树计时结果

固定完成深度4，每局面每臂6次计时，按ABBA、BAAB、ABBA串行运行。每个测量使用新进程，ready之后先进行不计时的深度1预热；模型初始化不计入下表，测量包含请求/响应开销。两臂使用相同预算，未触发深度中断。每一次结果都与基线严格比较完整逐层节点、全部候选及分值、最终走法，差异必须为零。

## 正确性与安全验证

三个变体分别完成，全部通过：

- 5局面×浮点/量化×普通/ASan+UBSan，共20个定向检查；612次合法转换的整体神经State恢复，严格逐层节点/全部候选/最终走法相等，超时后的后续请求恢复。
- 当前规则套件普通和ASan+UBSan各414组、11874次转换，分别核对JS规则、合法应手、揭子与私有暗俘等。
- 5局面1/4工作线程逐层节点、全部候选和分值严格相等。全明局面复制同一已知世界来实际覆盖四工作线程。
- 0/5/25/100毫秒预算中断与恢复；实际异步工作线程上127层push/pop，随后触发真实安全深度保护，恢复后整体状态一致。这不是127层完整搜索。
- 8工作线程合计16000次并发只读推理一致。此项及ASan/UBSan不等于ThreadSanitizer证明。

[验证清单](../../benchmarks/jqe-speed-2026-11-09/validation.json)记录各证据文件与导出字节哈希。没有增加其他网络维度/王位分桶模型测试，也没有重新运行独立上游推理oracle；与已验证冻结实现的严格等价范围以上述输入和测试为限。默认引擎没有变动，不能把本实验检查称为全仓库回归。
