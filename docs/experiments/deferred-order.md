# 延迟稳定排序：2026-11-05 独立实验

候选基于固定 C7，而非直接替换默认稳定引擎。保留 8 个暗子样本、原 HCE、全根覆盖、概率和隐私约束；不改节点定义、主深度限制或时间控制。
优化只先取稳定排序的第一着；确实访问第二着时再完成原排序。所有后续访问顺序及同分顺序保持原样。

## 已完成的检查与筛选

诊断四个已知局面：大量宽节点在访问少量候选后结束，支持研究延迟排序。
先前稳定索引堆已通过正确性，但六局面三轮配对完成同搜索的几何平均速度比仅 0.933，约慢 7.2%，淘汰。
新候选使用相同六局面、三轮换序；速度比 1.0323，最差局面 0.9972，超过预先固定的 1.03/0.95 筛选门槛。
首个全暗控制局面固定工作量速度比 1.0636，重残局 1.0679；不是每个残局都有收益。

Release、ASan/UBSan、TSan 均通过：同分稳定顺序属性、40 个有限搜索、6 个中断预算、414 个规则视角/11874 次走子撤销、3 个无 TT 参考，以及取消、暗俘隔离和旧 203 分反例。
源文件 SHA256 `6a3b23aaa1a6820dfbd1b89f897eeb2574b59fee827d1ab35c4ac93beee7b5aa`；生成单元测试源 SHA256 `308c708c56eed625a32aacd042aecd328e79fa5d087342e9e5693493b9a35daa`。
两个校验测试可从固定 C7 精确再生候选及被淘汰的堆原型，不发布本机构建产物。

技术失败、超过2060ms宽限的技术超时、保底着法均0。原稳定版的正常host-stop保留最后完整轮次，不计作故障。预先定义的不足1秒短搜索单列，完整保留。
快速制胜局面候选中位 8.85ms，Pika 5.56ms：Pika 仍更快；不能据其巨大深度数字或瞬时 NPS 声称完整搜索更深。
七个持续搜索局面的候选原生 NPS 中位数均高于 Pika，仅说明这组预选局面的这一指标。

限制：跨引擎节点含义不同；我方节点已累加全部样本，不能再乘 8。原稳定版截止遥测多为近似计数，候选/C7有精确完成计数标识，Pika为最后UCI报告；原始标识和三次重复的最小/中位/最大值均保留。
原稳定版全明单世界实际只用一线程，候选/C7 用四线程根并行，因此相对稳定版的残局增益包含并行收益；延迟排序的单独收益应看 C7 对照。
C7/Pika 使用 64MiB TT 上限，原稳定版的旧散列表分配不同，实际 RSS 也不等同。
同机串行、顺序轮换，并在试玩服务忙时暂停自己的测试；旧未知构建的状态仍未知，不能保证完全排除环境噪声。
全暗初始公共盘面是已知控制，其余七局面在本次测量前固定；稀疏残局为库存合法的编辑局面，不声称可达。
候选的完整迭代及最深走子路径中位数通常与 C7 相同，更多节点不等于棋力更强。
