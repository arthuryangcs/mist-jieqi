# 手动同步辅助盘与自动推荐

本轮支持把另一款软件里的实际走法手动同步到本地辅助盘。默认引擎仍是稳定的 C++ 核心，未切换到实验算法。

## 使用

1. 刷新 `http://127.0.0.1:8766/`，进入“对局辅助 / 分析”。
2. 选择“我执”红方或黑方，需要时翻转棋盘；点击“标准初始局面”重新录入，或沿用当前对局副本。
3. 保持“同步”，先点当前方棋子，再点亮起的合法落点。双方实际走棋后都按这个方法同步。
4. 暗子移动时填写实际揭开的身份；若你吃到敌方暗子，可点选被吃身份，也可留空并保留为未知。对手吃到你的暗子不填写它的身份。
5. 默认已勾选“自动分析”，进入辅助盘及同步、修正后会更新当前行棋方的推荐；也可取消勾选，再手动点击“分析当前局面”。搜索完成后点击“同步推荐一步”，先核对从起点指向落点的箭头，再确认。暗子仍需填写实际揭子结果，不使用采样身份替代。

普通对局中的分析完成后，“在辅助盘同步推荐”也可进入副本并同步。不会更改原人机棋局。“撤回同步 / 修正”逐次恢复局面；取消补录不走子；重置辅助盘保留可撤回记录。页面刷新不保存对局。

摆放修正、行棋方、已知离盘身份和未知库存仍可编辑。点击“摆放”后，点空位在附近的棋子图标菜单中选择添加，点已有棋子直接删除；取消菜单不修改局面，添加和删除均可逐次撤回。暗子只允许添加到己方原位。改完可点击“同步”。手动修正会重置辅助盘步数和重复记录；仅按实际走法同步会保留这些记录。未知库存与明子数量不一致时拒绝提交。

## 自动分析与同步箭头

连续修正合并等待300毫秒，只搜索最新有效局面。开始选择走法、等待揭子/暗俘补录或校验不通过时不启动；确认后分析新的公开观察。撤回、重置、调整思考时长/引擎和切换执棋方会取消旧请求并更新分析。切换模式、取消勾选或点击停止会取消尚未启动的计时器和正在运行的搜索；停止还会关闭开关，后续修改不会自行恢复。搜索失败不会循环重试。

自动分析只更新推荐，不自动执行着法，也不持续重复搜索未变化的局面。现有相同观察与预算缓存仍可复用；始终沿用用户选择的信息视角。

搜索每完成一层，就用SVG箭头、起终点标记和文字坐标更新推荐；结束后保留最终推荐。只有当前信息视角的分析可以显示箭头，人机模式不会展示黑方私有观察产生的搜索。新搜索、修改局面或切换视角会清除旧推荐，迟到响应不重新绘制。

推荐同步有独立确认阶段，包括明子推荐。确认框在落点附近浮动显示，空间不足时放到上方，并限制在可视区域；滚动、缩放和翻转棋盘时重新定位。补录身份直接点车、马、象、士、炮、兵图标，不使用下拉菜单；移动暗子的身份必填，被吃暗子可点“?”或不选作为未知，重复点已选的被吃身份也可清除。确认或取消后立即隐藏待同步箭头和浮层；新局面开始搜索后显示新的推荐。手动同步明子仍直接提交。

界面已移除大段常驻说明，库存与视角折叠收起；保留搜索设置、推荐、必要状态和错误提示。我执、同步/摆放、行棋方改为同排直接按钮，红黑用颜色区分；思考时长与选项同行，分析和停止分列两端。详细规则仍在README。

## 自动对战推荐

每次搜索开始先展示等待首个完整层；完整层到达后更新推荐起终点、深度、评分和候选。完成落子后明确标注“已落子”；下一方开始前清除旧结果。搜索开始时信息视角跟随行棋方，手动切换视角后不展示另一视角的搜索。人机对战仍不展示黑方私人信息产生的分析。

搜索期间、没有完整推荐或正在补录身份时，推荐按钮旁会显示不能应用的原因。自动对战已执行的结果不可再次执行。重开、撤回和切换模式会取消旧请求并丢弃迟到结果。
