# 对赛收尾计时试验

本目录把先前未测试的计时草稿整理为独立、已验证的对照工具；不由默认网页或默认服务导入。唯一优化变量是本方控制器提前40ms停止，底层仍为同一当前稳定C++二进制。

结果、完整协议、失败记录、样本限制与复现步骤见 [收尾预留报告](../../../docs/experiments/clock-reserve.md)。原始数据在 `benchmarks/clock-validation/`，临时日志、停止标志及进程锁只在 `.cache/clock-validation/`。

- `engines.mjs`：原生与固定Pika的端到端时钟、收尾及事件循环记录。
- `check.mjs` / `benchmark.mjs`：注入检查和固定名义预算基准。
- `matches.mjs`：冻结新布局及来源哈希，串行执行一局，使用当前第三次重复落子方判负规则。
- `verify.mjs`：回放所有实际走法、公私观察、时限和结果。
- `rule-probe.mjs`：正式对局完成后，使用实际Pika验证即时重复判负的UCI根约束。
- `report.mjs`：汇总胜和负、得分率、技术失败、时间及限制；不自动启用任何版本。

现有冻结证据不要覆盖。复跑应先另存原证据；若使用新目录，需要在 `common.mjs` 中显式指定新的 `dir` / `cache`，重新执行检查、基准和freeze，形成新的来源哈希。固定对手路径必须通过 `JIEQI_ENGINE_PATH` 指向已获授权且哈希匹配的二进制，不会下载或重新编译它。
